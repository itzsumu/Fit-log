# 💪 FitLog — Workout Library

A dark, no-nonsense gym companion: pick a lift, lock it into today's plan, and watch the week's work add up.

## 🛠️ Technologies Used
- Next.js 14 
- React 18
- Tailwind CSS
- Lucide React icons
- Oswald + Inter 

## ✨ Key Features
1. **Workout Library** — 12 lifts from the API in a responsive 3-column grid with a loading animation.
2. **Sort & Search** — Sort by Duration, Calories or Rating, and search by name or muscle tag.
3. **Workout Details** — Two-column page with key specs, 4-step instructions, and toast feedback.
4. **My Plan** — Today's Plan and Saved tabs with live Exercises / Minutes / Calories metrics.
5. **Mark as Done & Remove** — Manage your plan with toasts, a 5-lift cap, and localStorage persistence.

Also: custom 404 page, live navbar badges, fully responsive layout.

## 🚀 Getting Started
```bash
npm install
npm run dev
```
